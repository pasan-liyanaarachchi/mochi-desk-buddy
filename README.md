# Mochi Desk Buddy 🤖

A custom-built, interactive desktop companion. Mochi functions entirely offline, combining a quirky digital personality with practical desk widget features.

## ✨ Features
* **Animated Personality:** OLED eyes that naturally blink and look around.
* **Motion Reactions:** Shaking Mochi makes him dizzy, followed by a grumpy cooldown phase.
* **Desk Widget Mode:** On a double-tap, the display switches to show the current time, date, and a dynamic 4-bar battery indicator.
* **Daily Motivation:** Displays randomly selected motivational quotes stored directly in the microcontroller's flash memory.

## 🛠️ Hardware Stack
* **Display:** SSD1306 OLED (128x64)
* **Motion Sensor:** MPU6050 6-axis Accelerometer & Gyroscope
* **Timekeeping:** DS3231 Real-Time Clock (RTC) module
* **Software:** C++ / Arduino IDE environment
